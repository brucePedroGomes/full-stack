Frontend

I chose [React](https://react.dev/learn) with [TypeScript](https://www.typescriptlang.org/docs/) because the task board has many small parts that change often. Components keep each part simple, and types catch mistakes before the browser does.\
The app is one page. It talks to the Django API under `/api`.

- [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview)
- [Axios](https://axios-http.com/docs/intro)
- [Zod](https://zod.dev/)
- [Tailwind CSS](https://tailwindcss.com/docs)
- [Headless UI](https://headlessui.com/)
